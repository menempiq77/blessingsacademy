# Adding New Articles

Use the existing article pages in this folder as the template.

Recommended workflow:

1. Duplicate one of the current article `.html` files.
2. Rename it with a clear SEO slug such as `online-quran-classes-for-beginners.html`.
3. Update the page title, meta description, canonical URL, Open Graph tags, JSON-LD `Article` schema, heading, image, and article body.
4. Add the new article card to `articles/index.html`.
5. Add the new article URL to `sitemap.xml`.

For best SEO:

- Keep one main topic per article.
- Use a clear H1 that matches the search topic.
- Write at least 600 words of useful original content.
- Add 2-3 internal links to related pages.
- Include one WhatsApp CTA related to the article topic.
